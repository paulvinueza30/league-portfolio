# Welcome to My Blog

This is the first post in the new file-based blog system!

## Features

- **Ultra simple markdown** - No complex formatting needed
- **Git-based workflow** - Just write and push
- **Automatic deployment** - GitHub Actions handle everything

## How it Works

1. Create folder: `api/posts/my-post/`
2. Add `post.md` with frontmatter
3. Push to GitHub
4. Automatic deployment

That's it! No database, no CMS, just files.
